## Запуск локально

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере.

Для проверки GitHub Pages и предпросмотра ссылок используйте опубликованный URL. Некоторые возможности браузера и кэширование favicon могут отличаться при открытии файла через `file:///`.

## Публикация

1. Загрузить файлы в репозиторий GitHub.
2. Открыть Settings → Pages.
3. Выбрать Deploy from a branch.
4. Выбрать ветку `main` и папку `/(root)`.
5. Сохранить настройки.
6. После публикации проверить:
   https://martinminart.github.io/portfolio/

Публикация не является мгновенной.
