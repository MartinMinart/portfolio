📋 Что сделано руками

1. Сбор и объединение данных

Собрал данные из 1С, Excel-журналов и бумажных рапортов. Привёл к единому формату через Python/pandas (JOIN по сотруднику, дате, операции).

2. Очистка и валидация

Убрал дубли, обработал пропуски, отметил подозрительные значения (отрицательное время, нелогичные статусы).

3. Расчёт метрик

Для каждого сотрудника и смены рассчитал: выработку, соблюдение сроков, качество, нагрузку, стабильность.

4. Построение витрины

Сформировал витрину employee_performance с основными показателями.

5. Визуализация

Построил дашборд в Power BI с drill-down до уровня смены и фильтрами по цеху/участку.

6. Интерпретация

Показал руководству: где перегрузки, где брак, где системные просадки. Рекомендации по корректировке загрузки.

✅ Результат

Руководство получило инструмент для объективной оценки сотрудников, выявления узких мест и повышения общей эффективности цеха. Система внедрена в пилотном режиме на 3 участках.
